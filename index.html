Mohr's Circle — Stress
Three circles in the (σ, τ) plane:
σ1–σ2: c = σ1+σ22,  r = |σ1−σ2|2
σ2–σ3: c = σ2+σ32,  r = |σ2−σ3|2
σ1–σ3: c = σ1+σ32,  r = τmax
